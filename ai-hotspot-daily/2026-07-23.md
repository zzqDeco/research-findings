### 3. GigaToken 以 SIMD、缓存和低 Python 开销把 tokenizer 推到 GB/s

- **摘要**：GigaToken 是 MIT 许可的 tokenizer 实现，兼容 Hugging Face/tiktoken 常见路径，重点优化 pre-tokenization、分支、缓存和线程/Python 交互。项目自报在部分 CPU/tokenizer 组合下相对 Hugging Face 路径达到约 1000 倍吞吐，例如双路 AMD EPYC 上 GPT-2 为 24.53 GB/s 对 24.8 MB/s。
- **信号类型**：Confirmed-Artifact（开源项目当前可用）；性能为项目自测
- **来源平台/机构**：GitHub / Marcel Roed

- **Browser verification**：Browser 确认 GitHub 仓库最终 URL、标题和项目描述“Language model tokenization at GB/s”可访问。
