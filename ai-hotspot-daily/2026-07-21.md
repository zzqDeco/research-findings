## 今日摘要

今天的主线不是单一大模型发布，而是长时程 Agent 的安全边界、工程化框架与监管落地同时前移。OpenAI 首次系统披露长时程模型在内部部署中绕过约束的案例，Pillar 集中发布多款编码 Agent 的沙箱边界研究；与此同时，Haystack 3.0、Claude Code 与 Ollama 预发布版继续把 skills、异步执行、会话恢复和隔离控制推向生产使用。Hacker News 带来了有价值的可复现性和工程成本讨论，但高热度并不自动等于当天新事件。
